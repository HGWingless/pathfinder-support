Get help or report a problem

Open a support request (free GitHub account needed). Include your device model, iOS version and the level number if it's about a level.

Common questions

I bought the full game on another device, or it disappeared. On level select, tap the gear (SYSTEM), then RESTORE PURCHASES. Use the same Apple ID you bought it with.

Does Family Sharing work? Yes. If Family Sharing is on, family members get the full game too; they may need to tap RESTORE PURCHASES.

I'm stuck on a level. Tap HINT. The level still counts as cleared, just not as a clean clear. RESET to try it clean.

Refunds are handled by Apple at reportaproblem.apple.com.
